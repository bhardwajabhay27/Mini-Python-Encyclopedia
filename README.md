# Mini Python Encyclopedia

## Python Learning & Practice Tool

### 1. Project Overview

**Mini Python Encyclopedia** is a beginner-friendly Python learning and
practice application developed as a CSE project.

The project combines two important parts of learning programming:

1.  **Learning concepts** through organized topic explanations.
2.  **Practising programs** through a collection of basic Python
    problem-solving programs.

The application uses a menu-driven interface so that the user can easily
navigate between different Python concepts and practice programs.

------------------------------------------------------------------------

## 2. Main Features

-   Lists

-   Sets
-   Dictionaries
-   Input and Output

-   Loops

Topics are organized into subtopics wherever required.

For example, the Operators section contains:

## 5. How to Run

### Requirement

Install Python 3 on your computer.

### Steps

1.  Download or clone the project.
2.  Open the project folder in a terminal or Python IDE.
3.  Run the Python file.

Example:

``` bash
python main.py
```

4.  The Main Menu will appear.
5.  Select an option by entering the corresponding number.

## 7. Educational Purpose

The project is designed to make basic Python learning more organized and
interactive.

Instead of keeping explanations and practice programs separately, the
application provides both in one place. This helps a beginner understand
a concept and then practise programming problems related to basic Python
and problem solving.
