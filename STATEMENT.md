# Project Statement

## Mini Python Encyclopedia -- Python Learning & Practice Tool

### Problem Statement

Beginners learning Python often have to use different resources for
learning programming concepts and practising programming problems. This
can make the learning process less organized and difficult to navigate.

The purpose of this project is to develop a simple, menu-driven Python
application that provides basic Python concepts and problem-solving
programs in one place.

### Proposed Solution

The proposed system, **Mini Python Encyclopedia**, is an interactive
command-line learning tool developed using Python.

The application provides two major learning modes:

-   **Learn Concept:** Provides explanations of important Python topics
    and their subtopics.
-   **Practise Codes:** Provides a collection of 25 basic Python
    problem-solving programs.

The application also provides navigation between topics using previous,
next, and main-menu options.

### Objectives

The main objectives of the project are:

1.  To create a beginner-friendly Python learning application.
2.  To organize basic Python concepts in a structured manner.
3.  To provide examples and explanations of important Python topics.
4.  To provide basic programming problems for practice.
5.  To demonstrate fundamental Python programming concepts.
6.  To create a simple menu-driven user interface.
7.  To improve programming logic and problem-solving skills.

### Scope

The project focuses mainly on fundamental Python programming concepts
and basic problem solving.

The learning section covers topics such as:

-   Operators
-   Variables
-   Data Types
-   Type Conversion
-   Strings
-   Lists
-   Tuples
-   Sets
-   Dictionaries
-   Conditional Statements
-   Loops
-   Functions and other basic concepts

The practice section contains 25 programs covering lists, tuples,
searching, sorting, number problems, mathematical problems and basic
decision-making.

### Expected Outcome

The final application provides a single place where a beginner can:

-   Read Python concepts.
-   Explore subtopics.
-   Navigate between topics.
-   Run basic Python programs.
-   Practise programming logic.

The project demonstrates how Python functions, loops, conditional
statements and data structures can be combined to create a useful
command-line application.
